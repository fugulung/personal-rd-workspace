# Windows 本機網頁介面測試的兩個陷阱

> 類別：References（實測經驗）。**狀態：兩項都在某個個人研發產品的介面煙霧測試中實際遇到並解決；環境與限制見文末。**

## 1. 測試伺服器綁不到連接埠（WinError 10013／Errno 13「存取權限不足」）
- **現象：** 伺服器明明沒人占用，綁定 `127.0.0.1:<port>` 卻被拒絕；不是程式錯誤。
- **原因：** Windows 保留了一批連接埠範圍（動態保留，隨機器與重開機而異），落在範圍內的埠不能綁定。
- **檢查：** `netsh interface ipv4 show excludedportrange protocol=tcp`
- **做法：** 測試用的預設埠先對照這份清單；本次實測 8777–8876 被保留，8791、8793 綁定失敗，8900 可用。要避開的是**範圍**，換一個鄰近的埠常常仍在範圍內。
- **未確認：** 這批保留範圍是由哪個元件（虛擬化、容器等）造成的，本次沒有追查。

## 2. Edge headless 的虛擬時間不會等伺服器的真實耗時
- **現象：** 用 `--virtual-time-budget=<ms>` 搭配 `--screenshot` 時，網頁裡的計時器被快轉；伺服器端要花幾秒的工作（例如讀 NAS 分析）還沒做完，預算就用完，截圖停在「載入中」。
- **注意：** `--headless=new` 下改用 `--timeout=<ms>` 沒有等到腳本執行，截到的是剛載入的空白頁（本次實測）。
- **做法：** 在啟動瀏覽器**之前**，由測試程式用真實時間完成慢的工作並預先產生要拍的資源（分析、縮圖等），再讓測試頁直接載入已完成的結果；只對瀏覽器端的互動使用虛擬時間。
- **取結果：** 測試頁用 `console.log("標記 " + JSON.stringify(...))`，啟動時加 `--enable-logging --v=0 --log-file=<檔>`，程式讀記錄檔解析。
- **適用：** 資料量小、伺服器很快時（例如合成測試資料）不受影響，本次的 73 項介面測試即是；問題只出現在對真實大資料夾截圖時。

## 測試環境與限制
Windows 11、Microsoft Edge（版本未記錄）、單機單次實測。保留埠範圍與 Edge 對 `--timeout` 的行為可能因機器、版本而異，請以本機實測為準。
